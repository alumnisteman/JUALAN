ResellerHub OS v2.4.0

Panduan API Shopee & Tokopedia

Langkah-langkah teknis untuk mengintegrasikan toko Shopee dan Tokopedia Anda ke dalam ekosistem ResellerHub OS untuk sinkronisasi inventaris otomatis.

MARKETPLACE

Shopee Open Platform

shopping_bag
01

Pendaftaran Developer

Kunjungi open.shopee.com dan buat profil Developer. Anda harus memilih antara Custom App (untuk penggunaan internal toko sendiri) atau Public App.

02

Testing di Sandbox

Gunakan lingkungan Sandbox untuk melakukan simulasi API call tanpa mempengaruhi data toko asli. Sangat disarankan untuk memvalidasi alur data di sini terlebih dahulu.

03

Kredensial Partner

Setelah aplikasi disetujui, dapatkan Partner ID dan Partner Key. Masukkan kredensial ini ke panel Dashboard ResellerHub Anda.

AI Tips

Pilih Custom App jika Anda hanya memiliki 1-5 toko pribadi. Ini mempercepat proses review oleh tim Shopee.

Tokopedia Console

storefront
01

Akses Developer Console

Daftarkan akun Power Merchant atau Official Store Anda di developer.tokopedia.com untuk mulai membuat aplikasi.

02

Approval & App ID

Ajukan aplikasi dan tunggu proses verifikasi. Setelah disetujui, Anda akan menerima Client ID dan Client Secret untuk autentikasi OAuth2.

03

API Playground

Gunakan API Playground yang tersedia di konsol untuk mencoba endpoint seperti 'Get Shop Info' atau 'Update Price' sebelum implementasi penuh.
