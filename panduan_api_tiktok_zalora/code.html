Zalora Integration

1

Seller Center Access

Buka sellercenter.zalora.co.id dan pastikan akun Anda memiliki akses Administrator.

2

OAuth Application Settings

Navigasi ke menu Settings > Integration > OAuth Applications untuk membuat profil API baru.

3

Token Generation

Generate Bearer Token menggunakan App ID dan Secret yang diberikan. Gunakan endpoint auth Zalora untuk refresh token setiap 30 hari.
